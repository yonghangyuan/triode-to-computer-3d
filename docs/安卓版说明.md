# 安卓版说明（APK）

## 这是什么

`android/out/Triode2Computer-0.1.0.apk` —— 把 3D 教学实验台装进一个极简 WebView 外壳的
**离线安卓应用**：

- 体积约 **229 KB**（网页资源 705 KB 被压缩进 APK）
- 完全离线：不申请 INTERNET 权限，页面、贴图、脚本全部在安装包内
- 横屏沉浸式全屏（`sensorLandscape`），自动隐藏状态栏
- `minSdk 26`（Android 8.0+），`targetSdk 34`
- 已内置手机布局：底部「控制台 / 仪表」两个抽屉按钮，3D 全屏显示
- 退出：返回键直接退出（没有网页历史可回退）

## 安装到手机

1. 把 APK 发到手机（微信/QQ/数据线/网盘均可）；
2. 在手机上点击 APK，若系统提示"禁止安装未知来源应用"，按提示允许"文件管理器/浏览器"安装；
3. 安装完成后桌面出现「三极管到计算机」图标，点开即可，**不需要联网**。

> 微信里直接点 APK 通常无法安装，需要"用其他应用打开"或先保存到文件管理器。

## 从源码重新构建

前提：JDK 17、Android SDK（含 build-tools / platforms，Android Studio 自带即可）。

```powershell
cd 计算机原理3D教学
npm install
npm run build                                  # 生成 dist/index.html
powershell -ExecutionPolicy Bypass -File android\build-apk.ps1
# 产物：android/out/Triode2Computer-0.1.0.apk
```

构建脚本不依赖 Gradle：`javac → d8 → aapt2 → zip 注入 dex → zipalign → apksigner`，
全部使用 Android SDK 自带命令行工具，因此没有 `gradlew`、不需要联网下载依赖。

- 应用代码：`android/java/com/triode2computer/app/MainActivity.java`
- 清单：`android/AndroidManifest.xml`
- 图标生成、资源编译、签名（debug keystore，首次构建自动生成）都在 `build-apk.ps1` 里。

## 换内容 / 更新版本

1. 修改 `src/` 里的内容（或只改文案）；
2. `npm run build`；
3. 重跑 `android\build-apk.ps1`；
4. 改版本号：`android/AndroidManifest.xml` 里的 `versionCode` / `versionName`，并同步脚本里的 `--version-name`。

## 已知边界

- **debug 签名**：只适合自用/教学分发。上架应用商店必须换 release keystore，并准备软著、隐私政策、上架素材；教育类应用还涉及教育移动应用备案（详见 `平台化路线.md`）。
- **WebView 依赖**：渲染能力取决于手机系统 WebView 版本（Android 8+ 一般支持 WebGL2；极老设备可能降级）。
- **横屏固定**：本版强制横屏（3D 教学画面横向信息量大）。如需竖屏，改 `AndroidManifest.xml` 的 `screenOrientation`。
- 无网络权限、无统计埋点、无内购——是一个"干净"的离线教学应用，而不是平台客户端。

## 已验证

- 在 Android 16（API 36.1）模拟器上安装、启动、进入 3D 场景均正常（横屏、沉浸式、WebGL 渲染通过）；
- 网页内容与桌面版一致：4 个场景、交互冒烟测试 9/9 通过。
