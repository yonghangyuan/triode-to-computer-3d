# 从真空三极管到计算机 · 3D 原理实验台

一个**单文件、离线运行**的交互式 3D 教学模型：从 1906 年的真空三极管出发，
逐层搭建逻辑门、触发器、寄存器，最后让一台 4 位存储程序计算机在眼前单步运行。

> 面向教学与原理演示的**简化仿真**：电子、电场、屏流是物理模型驱动的；
> 门级、触发器级、CPU 级是可单步观察的逻辑仿真；3D 比例与剖切为教学可读性做了艺术化处理。

## 快速开始

**直接打开（推荐）**

- 双击 `dist/index.html`（单文件，离线运行）
- 需要支持 WebGL2 的现代浏览器（Chrome / Edge / Firefox / Safari 均可）
- 手机浏览器打开同一文件即可，横屏体验最佳

**从源码构建**

```bash
npm install
npm run build          # 产出单文件 dist/index.html
npm run build:dev      # 不压缩，便于调试
```

**自动化验证**

```bash
npm run smoke          # 交互冒烟测试：4 个层次、9 项检查、控制台零报错
node tools/shot.mjs --scene machine --out shot.png   # 无头浏览器截图
```

## 四个抽象层次

| 层 | 主题 | 你能做什么 |
| --- | --- | --- |
| **L1** | 真空三极管 | 解剖模型；调灯丝/栅极/屏极电压，看电子云、空间电荷、`Ip–Vg` 特性曲线、示波器与放大/开关 |
| **L2** | 逻辑门（NOR） | 两只三极管并联成 NOR；切换 A/B 看真值表、电路图、输出灯与导通路径 |
| **L3** | 触发器 · 寄存器 | 双稳态 SET/RESET、状态机图；4 位计数器用时钟脉冲逐位进位 |
| **L4** | 存储程序计算机 | 4 位 CPU：取指/译码/执行单步，内存、寄存器、总线、日志同步高亮，可运行两段程序 |

**快捷键**：`1`–`4` 切换层次，`Esc` 关闭导览。
初始导览可用 URL 参数 `?skip` 跳过（自动化截图用）。

## 已知边界

- 这是**教学仿真**，不是 SPICE：三极管用两条经典规律近似，未建模栅流、极间电容、温度漂移与噪声。
- 电子粒子是示意性的概率可视化（通过率 = `Ip / I_emission`），不代表单电子轨迹。
- 电子管 3D 模型做了正面剖切、比例压缩，便于观察内部结构。
- L4 的指令集是为教学设计的 4 位玩具 ISA，不对应任何真实历史机型。

详细说明见 **[docs/设计文档.md](docs/设计文档.md)**。
